PHASE 16 STAGE 16.3 MODEL-IN-THE-LOOP IDLE COGNITION
=====================================================

Status: complete
Date: 2026-05-07


MISSION
-------

Add the minimum model-in-the-loop idle cognition path: a bounded idle tick
that calls the model for a structured internal-thought candidate and records
the result as evidence without granting claims, actions, initiatives, or
self-approval.


IMPLEMENTATION
--------------

Added:

- `ModelIdleThought` schema in `src/nova/types.py`
- `model_cognition` field on `IdleTickRecord`
- `src/nova/agent/model_idle_cognition.py`
- `NovaRuntime.model_idle_tick(...)`
- CLI flag `--model-idle-tick`
- parser/validator for structured JSON internal thought output
- tests in `tests/test_model_idle_cognition.py`
- runtime smoke tests proving generation is skipped while paused

The model is asked for JSON only:

- thought
- trigger
- related_evidence_refs
- uncertainty
- candidate_goal
- action_proposal_intent
- unsupported_claim_flags


BOUNDARIES
----------

This stage does not:

- create user-visible self-claims
- allow desire, sentience, awareness, feeling, hidden-work, or background-work
  claims
- create initiatives
- execute tools
- approve actions
- touch filesystem, shell, network, GUI, system configuration, destructive
  actions, or external services

The model output is evidence input only. Unsupported claim language is flagged
and rejected by deterministic Python.

RESIDUAL LIMITS
---------------

This is still not full ongoing cognition.

The runtime can run one model-in-the-loop idle tick under explicit operator
control. It does not yet run a long-lived service loop, aggregate model
thoughts longitudinally, or use an Observer pass to classify the thought after
generation. Those are intentionally left for the next stage and closure
decision.

This stage does prove the critical architecture correction: Nova can now put
the model inside the idle cognition path and persist the result as bounded
evidence instead of only recording deterministic placeholders.
