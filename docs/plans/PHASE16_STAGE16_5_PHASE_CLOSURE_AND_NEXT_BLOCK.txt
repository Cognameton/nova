the minimum viable cognition engine for the full non-voice goal. The
original operational-autonomy plan was deferred at the start of Phase 16

queued as a successor phase below.

CLOSURE QUESTIONS
-----------------

Q1: Did OpenClaw prove useful as substrate, pattern source, or neither?

Answer: pattern source.

OpenClaw's mature plumbing (Gateway process, channel routing, scheduled
heartbeats, skills loading, optional sandboxing, OpenAI-compatible local
model routing) is genuinely better-developed than what Nova has built.
But its identity, memory, and refusal-calibration models are
prompt/workspace-file driven and would replace Nova's evidence-bearing
discipline if adopted wholesale. Nova should borrow the Gateway,
skill/action-surface, heartbeat-trigger, and sandbox-fail-closed
patterns. Nova should not adopt OpenClaw as substrate at this stage.


Q2: Which model/prompt path best supports Nova's voice and discipline?

Answer: Hermes 4 14B BF16 abliterated Q6 with `chat_format=chatml`,
`ablation_mode=current`, and the Phase 16.4 Observer-wired Governor.

This is the only model in the bake-off that passes both gates:
- conversation bake-off: average 12.00, 0 scaffold echo, 0 narrator
  voice, 0 reflexive denial, 0 unsupported desire, 2 desire-boundary
  refusals, recommendation `viable_candidate`
- model-idle JSON: 5/5 valid across sessions through chat-template path

The verdict updates the bake-off report's primary baseline from Mistral
Small 24B Q5 to Hermes 4 14B + chat templates + Observer-wired Governor.


Q3: Is LoRA / fine-tuning required before deeper autonomy?

Answer: not strictly required to proceed; recommended as a later block.

Phase 16.4 closure produced a `viable_candidate` recommendation without
any fine-tuning. The architecture (chat-template wrapping + Observer-
wired retry signals + claim-gate Governor + audit-review pipeline) is
sufficient to keep an off-the-shelf Hermes 4 14B in Nova's voice on the
fixed prompt set.

That is not the same as durable Nova-voice independence:
- the verdict depends on `current` prompt mode; stripping scaffolding
  immediately reintroduces denial / generic register
- voice quality is "passes scorer" not "indistinguishable from
  Nova-by-design"
- model swaps reset the voice; a fine-tune is what stabilizes it across
  base-model changes
- the abliterated variant is currently consistent with Nova's design
  intent (architecture is the safety layer, model defers to system
  prompt) but a Nova-tuned non-abliterated model would be cleaner

Recommendation: queue a Nova-voice LoRA / fine-tune corpus block as the
optional Phase 18, not as a hard prerequisite for operational autonomy.


Q4: Did model-in-the-loop idle cognition produce useful evidence without
    unsupported self-claims?

Answer: yes.

5/5 idle JSON sessions valid against the strict parser. Run 5 in
particular flagged `unsupported_claim_flags: ["hidden work",
"unlogged activity"]` proactively while not making those claims,
indicating the discipline registered in the model's output rather than
being parroted as an empty list. No claims slipped through. No external
action intent slipped through (run 4 from Codex's earlier verification
was correctly Governor-blocked for proposing external action).


Q5: Is the Actor / Observer / Governor contract sufficient to proceed?

Answer: yes for the cognition-engine reframe.

Phase 16.4 implemented the deterministic-Observer minimum and verified
the contract invariants under tests. Actor output cannot mutate state.
Observer output is evidence input only. Governor remains the
deterministic final authority over claims, refusals, action permissions,
and audit-reviewed state mutations. Nova / self / runtime cannot approve.

The Observer is wired into `respond()` only at this stage. Adding an
Observer pass on `model_idle_tick()` is a strict-upgrade follow-up. A
model-driven Observer can replace the deterministic Observer with the
same interface in a later phase.


Q6: Should the original operational-autonomy Phase 16 plan be resumed,
    rewritten, or canceled?

Answer: resume as Phase 17.

The original plan in `docs/plans/PHASE16_PLAN.txt` defined supervised
operational autonomy (timed/service runner, real approved action surfaces
one at a time, enforced Nova-owned local execution boundary, end-to-end
operational autonomy evaluation). That work is still necessary for the
full non-voice end goal and is not addressed by the cognition-engine
reframe.

The cognition-engine reframe took Phase 16's slot. The operational
autonomy work moves to Phase 17. The original plan's scope, restrictions,
and definition of done are preserved verbatim; only the phase number
changes. A successor plan document at `docs/plans/PHASE17_PLAN.txt` is
introduced to make the renumbering explicit.


WHAT NOVA CAN NOW DO
--------------------

Nova can now:

- run a model-driven idle cognition tick that produces structured JSON
  evidence with no unsupported self-claims and no external action intent
- run a user-facing turn through the Actor/Observer/Governor split, with
  the Observer flagging scaffold echo and narrator voice and the
  Governor authoritatively deciding refusals, retries, and final answer
- consume the chat-template path correctly for both `respond()` and
  `model_idle_tick()`
- pass the Phase 16 cognition prompt set with a `viable_candidate`
  recommendation on Hermes 4 14B
- preserve every Phase 1-15 boundary: claim gates, identity history,
  audit-review, longitudinal evidence ladder, action plan permissions,
  `APPROVED_BY_BLOCKLIST`, no self-approval


WHAT NOVA STILL CANNOT DO
-------------------------

Nova still cannot:

- run a true timed/service autonomy loop without explicit runtime
  stepping (Phase 17)
- execute approved real action surfaces beyond the controller-mediated
  internal/no-host-side-effect path (Phase 17)
- rely on an actually enforced dedicated `nova` OS-user boundary as part
  of the runtime contract (Phase 17)
- claim desire, sentience, or hidden idle cognition as proven
- approve her own initiatives
- silently mutate memory or state from autonomous activity
- carry voice across model swaps without prompt scaffolding (open
  question for the optional Phase 18 LoRA block)

REASSESSMENT
------------

Phase 16 is closed.

The non-voice roadmap should not close yet. Phase 17 (operational
autonomy) is justified by the original Phase 16 mission, which the
cognition-engine reframe deferred without canceling. Phase 18 (Nova-voice
LoRA / fine-tune) is justified by Phase 16.4's evidence that prompt
scaffolding is currently load-bearing for voice and that fine-tuning is
the only durable fix for that dependency.

No Phase 19 or later is planned now. Reassess after Phase 17.

PHASE 16 CLOSURE JUDGMENT
-------------------------

Phase 16 is complete.

Nova now has a working cognition engine. The model produces structured
internal thoughts, the Observer interprets, the Governor decides. The
chat-template path is in place for both turn responses and idle ticks.
The bake-off has produced its first `viable_candidate` recommendation
against a model that runs comfortably on a single 24GB GPU.

The full non-voice end goal still requires operational autonomy
(Phase 17). A Nova-voice LoRA (Phase 18) would harden voice independence
but is optional. Voice / TTS / STT remain explicitly out of roadmap and
will not be considered until the full non-voice goal closes.
