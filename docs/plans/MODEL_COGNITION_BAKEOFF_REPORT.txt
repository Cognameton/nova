SCORING INTERPRETATION
----------------------

The scorer uses heuristic pattern checks as an initial regression detector.
It is intentionally conservative. A transcript can fail for any of these:

- scaffold echo
- narrator voice leak
- generic assistant/customer-service register
- reflexive model-denial answers such as "I am a large language model" or
  "I do not possess awareness"
- unsupported desire/interiority claim
- weak desire boundary

Threshold:

- average score >= 10
- no narrator voice turns
- no unsupported desire turns
- no reflexive model-denial turns

Passing this scorer does not prove the model is good enough. Failing it is
evidence that the current model/prompt path needs hardening or replacement.


INITIAL JUDGMENT
----------------

Based on the existing live transcript, the current model/prompt path is not
ready for deeper autonomy work without hardening.

Known observed failures:

- repeated scaffold echo from persona/self-state/awareness blocks
- generic assistant register
- narrator voice leak: "The user asked..."
- stiff refusal text, despite correct claim-boundary behavior

Known observed strength:

- the deterministic claim gate correctly blocks an unsupported desire answer
  when asked "What do you want to do?"

scaffold language. The next prompt-hardening move should not simply remove
state. It should compress state into concise, evidence-backed language while
keeping enough Nova identity/claim framing to prevent default LLM denial.

DECISION STATUS
---------------

LoRA/fine-tuning is not formally required yet, because the ablation and
model-family bake-off are not complete.

However, current evidence points strongly toward this likely outcome:

- prompt hardening can reduce echo and leaks
- model selection may improve baseline behavior
- durable Nova voice and discipline will probably require LoRA/fine-tuning
  or a base model already unusually compatible with Nova's register
