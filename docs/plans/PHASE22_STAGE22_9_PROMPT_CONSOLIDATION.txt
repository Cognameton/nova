DECIDED DESIGN
--------------

Part 1 — type-safety fix (precondition for everything else):
  apply_proposal_to_self_state coerces by TARGET field type: if the
  SelfState field currently holds a list and proposed_value is str,
  apply [value] (her exact words, one entry — no clever splitting);
  if the field holds a str and proposed_value is a list, join with
  "; ". prior_value capture unchanged. Tests for both coercions and
  for the unchanged same-type paths.

Part 2 — apply the 20 stranded proposals:
  BACKUPS FIRST (the reversal path, see REVERSAL below). Then apply
  all 20 in chronological order via the existing operator CLI
  (--apply-self-model-proposal <id>), against the live config. Each
  application captures prior_value at apply time (shared 22.8 helper),
  so every one is individually revertible via
  revert_self_model_revision even though the records predate 22.8.
  Chronological order means each field ends at Nova's most recent
  proposed value — her latest stated intent: current_focus from
  2026-07-23T02:48, active_questions from 2026-07-23T09:52 (the
  proposal that expands beyond the frozen anchor question),
  continuity_notes from 2026-07-22T22:30. The daemon holds self_state
  in memory from startup, so the applied state reaches Nova at the
  same moment the rewritten prompt does: the next midnight rotation.

Part 3 — the rewrite (self_state_tick.py):
  Principles: one voice, addressed to Nova ("your self-inquiry log");
  every tool gets one honest sentence of purpose (recall_self and
  reflect had none, ever); no directive survives unless it either
  protects the contract or describes something real; net REMOVAL.
  Specifics:
    - emit_heartbeat: novelty mandate replaced with an honest-null
      permission mirroring 22.1's null-finding rule: record what you
      actually notice; if nothing new stands out, say so plainly —
      that beats rewording old observations. (Dissolves B1's novelty
      half. The user-message "already recorded — do not repeat these
      phrases" header stays: it is factual.)
    - grounding rule: single line permitting departure — ground in
      context and accumulated experience, follow your own observations
      when they point somewhere new. This ADOPTS Part D's soft-
      grounding hypothesis as the default and dissolves B1's other
      half and B3's forbid. tick_soft_grounding stays parseable but no
      longer switches anything (one line now); tick_drive_injection_
      interval and tick_drive_descriptive remain live Part D levers,
      untouched and OFF.
    - enter_exploration: "only for what you cannot pursue in a normal
      tick" REMOVED; neutral purpose line (bounded multi-tick inquiry
      on one topic); repeat-rationale rule kept in one gentle sentence
      (the contract's repetition-is-a-choice principle); 22.8b's "not
      the only meaningful choice" line REMOVED (it flipped the
      distribution — F11).
    - update_self_model: 22.8b's paragraph compressed to two
      sentences; writability wording still switched on
      nova_writable_inquiry_fields (never promise an ungated path);
      stays assertion-register-only per the membrane.
    - claim rule kept, with the register valve made explicit: do not
      claim desire/sentience/consciousness as established fact — open
      questions about them belong in an exploration (B4's designed
      resolution, now stated where the tension lives).
    - _EXPLORATORY_RULES: UNTOUCHED byte-for-byte. The membrane text
      is correct and she was never confused there.
    - JSON output format rules: unchanged (parser contract).

Part 4 — self-context truthfulness (self_context.py):
  - _ladder_summary_lines: standing counted over ALL active records
    (E1 fix); cluster_texts stays windowed to the last 200 for cost,
    labeled as such in the rendered line.
  - Pending-proposals line: counts only approval_required AND
    unapplied records ("awaiting operator review"), renders only when
    >0, so rate-limited inquiry records (unapplied by design) never
    resurrect E2's dead-letter message.

Part 5 — small fixes:
  - runtime._exploration_history_block: an active record from a prior
    session renders "(stranded at session end)" not "(active)" (E4).
  - configs/nova.qwen3-14b.live.yaml: system_prefix "/no_think"
    removed (E3). phase20 baseline config untouched (archived
    comparability).
